# Telegram Bot для транслитерации ФИО

Этот Telegram-бот принимает ФИО на кириллице и возвращает его на латинице.

## Требования

- Docker

## Установка и запуск

### Клонирование репозитория

1. Сначала клонируйте репозиторий на свой локальный компьютер.
```bash
git clone git@github.com:polina-kol/tg_bot.git
```
2. Постройте Docker-образ. Выполните следующую команду в терминале:
```bash
docker build -t bot .
```
3. Запустите контейнер с созданным образом, заменив <YOUR_TOKEN> на токен вашего бота, полученный у BotFather:
```bash
docker run -d -v $(pwd):/app -e TOKEN=<YOUR_TOKEN> bot
```
4. После запуска бота найдите его в Telegram и отправьте сообщение с ФИО, написанным на кириллице. Бот ответит вам с преобразованным ФИО на латинице.


### Примечание
Логи работы бота будут сохраняться в файл bot.log в той же директории, откуда был запущен контейнер.
